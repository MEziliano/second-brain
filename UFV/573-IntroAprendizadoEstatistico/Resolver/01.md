# Atividade Avaliativa 01

### Questão 01

Informe se a afirmação é verdadeira ou falsa.
**A média é uma medidad de dispersão**
**[RESPOSTA]** Falso

> A média é uma medida de tendência central, não de dispersão. Medidas de dispersão incluem variância, desvio padrão, amplitude total, amplitude interquartil, etc.

### Questão 02

Informe se a afirmação é verdadeira ou falsa.
\*\*Somente a média é suficiente para descrever um conjunto de dados de forma satisfatória.

**[RESPOSTA]** Falso

> A média por si só pode não ser suficiente para descrever um conjunto de dados de forma satisfatória, principalmente se os dados forem muito dispersos ou assimétricos. É importante considerar outras medidas, como a mediana, o desvio padrão, a variância, a amplitude total, a amplitude interquartil, etc.

### Questão 03

A covariância entre as variáveis X e Y foi igual a 0,98. Tal valor informa que existe uma forte assosiação linear negativa entre essas variáveis.
**[RESPOSTA]** Falso

> Na verdade, essa informação é falsa. Apesar da covariância ser positiva, ela não indica uma relação linear entre as variáveis.

### Questão 04

A correlação entre X e Y foi igual a -0,88 indicando uma forte associação negativas entre as variáveis.
**[RESPOSTA]** Verdadeiro

> Diferentemente da covariância, a correlação possui um intervalo mensurável, ou seja, através da informação de que a correlação é menor que -0,7 pode se dizer que se trata de uma assosiação negativa.

### Questão 05

O desvio padrão é o quadrado da variância.
**[RESPOSTA]** Falso

> Na verdade, o desvio padrão é a raiz quadrada, e não o quadrado da variância.
