### Questão 02

A soma de quadrado dos Resíduos é utilizada como função custo para construção das árvores de regressão.

**[RESPOSTA]** Verdadeiro.

> > Critério de Divisão (Splitting):

1. Ao construir uma Árvore de Regressão, o algoritmo (como CART) busca a melhor divisão para cada nó.

- O objetivo é minimizar a impureza dos nós filhos.
- Para regressão, a medida de impureza mais comum é a Soma dos Quadrados dos Resíduos (SQE) ou a Variância.
- Ou seja, a função custo local em cada passo greedy é minimizar a SQE dentro das regiões criadas pela divisão.

2. Predição Final:

- A predição em cada folha é a média dos valores alvo (y) dos dados de treinamento naquela folha.
- Sabemos que a média é o estimador que minimiza a soma dos quadrados dos erros. Então, a estrutura da árvore é construída para minimizar essa métrica.

### Questão 03

O modelo de regressão pode ser classificado como um método de aprendizado supervisionado.  
**[RESPOSTA]** Verdadeiro.

> >

1. Definição de Bagging (Bootstrap Aggregating):

- No Bagging clássico (aplicado, por exemplo, a Árvores de Decisão), cada modelo base (árvore) é treinado em uma amostra bootstrap dos dados.
- Em cada divisão (split) da árvore, o algoritmo considera TODAS as variáveis preditivas disponíveis para encontrar a melhor divisão.
- Portanto, o número de variáveis utilizadas na construção de cada árvore no Bagging é igual ao número total de variáveis preditivas (p).

2. Confusão Comum: Bagging vs. Random Forest:

- A afirmação descreve o comportamento do Random Forest, não do Bagging simples.
- No Random Forest, introduz-se uma aleatoriedade adicional: em cada split, o algoritmo seleciona um subconjunto aleatório de m variáveis (onde m<p) para considerar a melhor divisão.
  Essa restrição (m<p) é o que diferencia o Random Forest do Bagging de árvores e ajuda a decorrelacionar as árvores, reduzindo a variância do ensemble.
